البيت الألماني لمكافحة الحشرات والقوارض

الموقع جاهز للرفع على Vercel كموقع Static بدون build command.

الرفع: فك ضغط ZIP، ثم ارفع المجلد إلى GitHub واربطه بمشروع Vercel، أو استخدم Vercel CLI من داخل المجلد.

مهم قبل الإطلاق:
1. أضف الدومين الفعلي للموقع إلى إعدادات Vercel.
2. بعد اختيار الدومين، أنشئ sitemap.xml بروابط مطلقة لهذا الدومين، وأضف Sitemap: https://YOUR-DOMAIN/sitemap.xml في robots.txt.
3. راجع النصوص ومعلومات الخدمات ومدى توفرها الفعلي قبل النشر.
4. أضف تقييمات عملاء حقيقية بموافقتهم في reviews.html؛ لا توجد تقييمات مختلقة.
5. الخط Cairo يستخدم Google Fonts؛ توجد خطوط بديلة إذا تعذر تحميله.
6. الصور: الشعار المرفق من العميل فقط؛ لم يتم نسخ صور أو مقالات الموقع المرجعي.
7. هذا تصميم مستقل مستوحى من وصف المستخدم، وليس نسخة بكسل ببكسل من الموقع المرجعي الذي تعذر فحصه مباشرة.
